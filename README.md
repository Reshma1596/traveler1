# 🌍 Traveler Greeting Web App

A simple and interactive web application built using HTML, CSS, and JavaScript that greets the traveler with a personalized message. The program takes the user's name as input, validates it, and displays a greeting or an error message if no name is entered.

---

## 🚀 Features

- Takes user name as input
- Displays personalized greeting message
- Input validation using conditional statements
- Shows error message if input is empty
- Interactive and user-friendly interface
- Styled using custom CSS and background images

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)
